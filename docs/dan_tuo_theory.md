# 胆拖结构理论：为什么"追热号"在概率上毫无意义

> 版本：v2.5.0 · 2026-10-22
> 对应实现：`data/dan_tuo_exact.py` · `tests/test_dan_tuo_exact.py` · `scripts/verify_dan_tuo_exact.py`
> 本文所有结论均为**精确超几何推导**，不是统计观测（观测只能给出近似）。

---

## 0. 一句话结论

> **固定号码池下，胆拖方案的中奖率只取决于胆码的个数，
> 与"胆码具体选哪几个号"完全无关。**

因此追热号、追冷号、追遗漏、追生日号，在概率上**完全等价**。

---

## 1. 设定与符号

以超级大乐透为例（前区 35 选 5，后区 12 选 2，每注 2 元）。

一个胆拖方案由四个参数决定：

| 符号 | 含义 | 取值约束 |
|---|---|---|
| `k` | 前区**胆码个数** | `0 ≤ k ≤ 5` |
| `t_f` | 前区**拖码池大小** | `t_f + k ≤ 35`，且 `t_f ≥ 5 - k` |
| `m` | 后区**胆码个数** | `0 ≤ m ≤ 2` |
| `t_b` | 后区**拖码池大小** | `t_b + m ≤ 12`，且 `t_b ≥ 2 - m` |

展开后的注数：

```
注数 = C(t_f, 5 - k) × C(t_b, 2 - m)
```

**注意这四个参数里没有"具体哪几个号"。** 这是全文的关键。

---

## 2. 第一步：把开奖分类

开奖的前区 5 个号，按落点分成三块：

- `d_f` 个落在**胆码集**里
- `p_f` 个落在**拖码池**里
- 剩下 `5 - d_f - p_f` 个落在**池外**（35 - k - t_f 个号里）

该类开奖的**组合数**：

```
C(k, d_f) × C(t_f, p_f) × C(35 - k - t_f, 5 - d_f - p_f)
```

总开奖数 `C(35, 5)`。后区同理（`C(12, 2)` 为分母）。

于是每个开奖都被归入一个分类 `(d_f, p_f, d_b, p_b)`，
每类的概率可以精确算出。

---

## 3. 第二步（关键）：命中数的可达集合是确定的

给定前区分类 `(d_f, p_f)`，我们从 `t_f` 个拖码里挑 `need_f = 5 - k` 个。
设挑中的号码里，恰好有 `h` 个落在开奖的拖码命中子集 `S_f`（`|S_f| = p_f`）里。

`h` 的取值范围：

```
h_min = max(0, need_f - (t_f - p_f))     ← 尽可能全挑不在开奖里的
h_max = min(need_f, p_f)                 ← 尽可能全挑在开奖里的
```

**区间内每一个整数都可达** —— 这是组合论的基本事实（两个集合交集大小的取值构成连续区间）。

> ### ★ 关键观察
> 这个可达集合**只依赖 `p_f` 的个数**，
> 与 `S_f` 具体是哪几个号**毫无关系**。

因此，给定分类后：

```
我们这套注能产生的前区命中数集合 = { d_f + h : h ∈ [h_min, h_max] }
```

这是一个**确定的集合**，不是随机的。

后区同理：

```
后区命中数集合 = { d_b + n : n ∈ [max(0, need_b-(t_b-p_b)), min(need_b, p_b)] }
```

---

## 4. 第三步：判定"有没有注能中奖"

记：

- `M_前` = 前区可达命中数集合
- `N_后` = 后区可达命中数集合
- `W` = 中奖组合集合 `{(m, n) : prize(m, n) > 0}`

某注 `(i, j)` 中奖 ⟺ `(m_i, n_j) ∈ W`。

由于展开结果是**笛卡尔积**，前区组合 `i` 与后区组合 `j` 是**独立选取**的：

- 对任意 `m ∈ M_前`，存在组合 `i` 使 `m_i = m`
- 对任意 `n ∈ N_后`，存在组合 `j` 使 `n_j = n`
- `i` 与 `j` 的选择相互独立

于是：

```
∃ 注中奖  ⟺  ∃ m ∈ M_前, ∃ n ∈ N_后 使 (m, n) ∈ W
```

右边**只依赖 `(d_f, p_f, d_b, p_b)` 与四个结构参数**，与号码身份无关。

同理，对任意奖级 `L`：

```
P(至少中一注奖级 L) = 1[ ∃ m ∈ M_前, ∃ n ∈ N_后 使 prize(m, n) = L ]
```

也是完全确定的指示函数。

### 结论

```
中奖率 = f(k, t_f, m, t_b)      ← 只有结构参数
```

**在固定号码池下**，`t_f`、`t_b` 固定，于是中奖率只取决于**胆码个数 `k` 与 `m`**。

---

## 5. 第四步：为什么"选哪几个号"完全无关

上面的推导里，唯一用到"具体号码"的地方是第三节的组合计数——
而组合计数只依赖集合的**大小**，不依赖元素身份。

换句话说：把胆码从 `06` 换成 `35`，只是把 840 注的集合换了一个（同一结构下的重新标记），
开奖对号码完全对称 ⟹ 概率分布**逐点相同**。

**这是恒等式，不是统计近似。**

### 实证

`tests/test_dan_tuo_exact.py::test_t3_win_rate_depends_only_on_dan_count`
对每个 `(k, m)` 组合枚举 12 组不同号码做胆，断言

```
(注数, 期望返奖, 中奖率) 三元组完全相同
```

实测结果：

| 结构 | 12 次随机换号的中奖率 |
|---|---|
| 1 前胆 / 1 后胆 | 42.9661894083%（min = max） |
| 2 前胆 / 0 后胆 | 47.4297050198%（min = max） |
| 0 前胆 / 2 后胆 | 28.2649276719%（min = max） |
| 2 前胆 / 1 后胆 | 42.9661894083%（min = max） |

**bit-for-bit 相同。**

---

## 6. 期望值：结构完全无法影响

单注期望奖金：

```
E[单注奖金] = Σ_{m,n} P超几何(m, n) × prize(m, n)
```

`P超几何` 只依赖**彩种规则**（35/5/12/2），不依赖你选了哪些号，也不依赖胆拖结构。

因此方案的总期望：

```
E[总返奖] = 注数 × E[单注奖金]
E[净收益] = 注数 × (E[单注奖金] - 2)
```

**完全线性。** 所以：

- 换胆码 → 期望不变
- 换胆码个数 → 期望不变（只是注数变，注数变就按比例变）
- 追热号 / 追冷号 / 追遗漏 → 期望不变

> 大乐透：单注期望净收益 **-0.9407 元**（返奖率 52.96%）
> 双色球：单注期望净收益 **-0.8570 元**（返奖率 57.15%）
>
> 凯利公式 `f* = 0` —— 数学公式的建议是"不下注"。

## 7. 结构矩阵（实测，固定号码池 前 11 / 后 5）

| 前胆 \ 后胆 | 0 胆 | 1 胆 | 2 胆 |
|---|---|---|---|
| **0 胆** | 47.43% (4,620注/9,240元) | 43.00% (1,848注/3,696元) | 28.26% (462注/924元) |
| **1 胆** | 47.43% (2,100注/4,200元) | 42.97% (840注/1,680元) | 28.26% (210注/420元) |
| **2 胆** | 47.43% (840注/1,680元) | 43.00% (336注/672元) | 28.26% (84注/168元) |
| **3 胆** | 45.74% (280注/560元) | 41.28% (112注/224元) | 24.65% (28注/56元) |
| **4 胆** | 35.12% (70注/140元) | 29.17% (28注/56元) | 15.50% (7注/14元) |
| **5 胆** | 22.96% (10注/20元) | 15.13% (4注/8元) | 6.67% (1注/2元) |

读法：

1. **横向看**（后区胆码数固定）：前区胆码数 0/1/2 中奖率**完全相同**（47.43%），
   前区拖码池够大时，前区胆码几乎不构成约束。
2. **纵向看**（前区胆码数固定）：**后区胆码数才是主要约束**。
   后区 0 胆 → 47.43%，1 胆 → 43.00%，2 胆 → 28.26%。
   原因：后区号码总数只有 12，胆码一旦不出，对应后区直接归零。

## 8. 精确解 vs 蒙特卡洛：两套独立实现的交叉验证

`data/dan_tuo_exact.py`（全枚举）与 `scripts/verify_dan_tuo_exact.py`（30 万次抽样）
是**两套完全不同的算法**。它们互相验证时抓出了两个真实 bug：

### Bug 1：把"随机一注未中"当成了"所有注都未中"

旧公式用 `lose_mass = Σ_cat P(cat) × P(随机一注未中 | cat)`，
但胆拖共享胆码时，各注之间**不独立**（它们共用同一个胆码），
"所有注都未中"的概率 ≠ "随机一注未中"。

**症状**：把 840 注的中奖率算成 6.67%，而真实值是 42.97%（差 6 倍）。

**修法**：利用第三节的可达集合，把"该分类下能否中奖"变成**确定的指示函数**。

### Bug 2：同名奖级对应多个命中组合时被重复计数

大乐透九等奖对应 **4 组**命中组合：`(3,0) (1,2) (2,1) (0,2)`；
双色球六等奖同样对应 4 组。统计"至少中一注九等奖"时若按组合逐个累加，
会算出 **> 100%** 的概率。

**修法**：按奖级做 OR 合并后再统计。

> 这两个 bug 都只在**交叉验证**里暴露 —— 单套实现自测永远"看起来对"。

## 9. 对用户问题的直接回答

> **"能不能推算下期冷热号？"**

能算，但算出来的是**对过去的描述**，不是对未来的预测。

- 本项目的 v1.6.0 热号幻觉实验：2022-24 的热号去预测 2025-26，
  命中 190 注 vs 期望 192.9 注（**z = -0.22**，与随机无差异）
- 相邻年 Top-10 重合数 ρ = +0.13（z = +0.75，仍不显著）
- 按冷热分档统计 2938 期实际出现次数：**最热档 421 / 最冷档 463**，
  均匀理论值 **419.7**，误差棒内无单调趋势

所以"热号更容易出"这件事，在真实数据里**找不到任何证据**。

> **"那我推演的胆拖号码怎么样？"**

从**结构**看有优化空间（见第七节：后区 1 胆是主要约束）；
从**号码**看没有任何可优化的地方——因为你选哪几个号做胆都不影响中奖率。
